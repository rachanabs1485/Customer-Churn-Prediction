Customer Churn Prediction
📌 Overview

This project aims to predict whether a customer will leave a company (churn) using Machine Learning classification techniques. It helps businesses identify high-risk customers and take preventive actions to improve retention.

🧠 Problem Statement

Customer churn leads to revenue loss and increased acquisition costs. The goal is to build a predictive model that classifies customers as Churn (Yes/No) based on their behavior and service usage.

🎯 Objectives
Perform data preprocessing and cleaning
Conduct Exploratory Data Analysis (EDA)
Apply feature engineering and encoding
Train multiple classification models
Evaluate model performance
Select the best-performing model
📂 Dataset

The dataset includes customer details such as:

Demographics (gender, age)
Account information (tenure, contract type)
Billing details (monthly charges, total charges)
Services (internet, tech support, etc.)

🏆 Results

The models were compared based on performance metrics, and the best model was selected for predicting customer churn effectively.

💡 Key Insights
High monthly charges increase churn probability
Customers with short tenure are more likely to churn
Month-to-month contracts show higher churn rates
